# 📅 Engineering Student's Weekly Schedule

A clean, responsive HTML/CSS web page that displays a structured weekly study schedule tailored for engineering students.

## 🚀 How to Run & View

1. **Live Demo:** Visit the hosted page directly at `YOUR_URL_HERE`.
2. **Run Locally:**
   * Clone or download this repository.
   * Open `table.html` directly in any web browser.

## 📌 Overview

This project provides a simple, clean interface to help engineering students manage their time and balance core tasks throughout the week—ranging from coding and problem-solving to lab work and project development.

## ⚙️ Features

* **Weekly Breakdown:** Complete schedule covering Monday through Sunday with allocated focus areas and time limits.
* **Custom Styling:** Designed with a dark navy background (`#02142c`) and dark green headers (`#07573c`).
* **Interactive UI:** Table rows feature a light green highlight effect (`#abeed29f`) on hover for better user experience.
* **Lightweight:** Built entirely with plain **HTML5** and **CSS3** with zero external dependencies.
